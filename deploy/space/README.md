# Ask about Kheirie El Hariri

A recruiter-facing chatbot that answers questions about Kheirie El Hariri's background using only
approved materials. It says when something is not documented instead of guessing.

Each visitor gets 3 AI answers per day; after that, the chat shows the passages from the approved
materials that best match the question.
